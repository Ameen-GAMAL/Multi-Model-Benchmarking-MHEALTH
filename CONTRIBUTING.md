# Contributing

Use the repository's GitHub issues and pull requests for reproducibility problems or code changes. Include the benchmark command, source and input fingerprints from the run manifest, and Python version. For loader or split issues, include generated sensor values or synthetic steps. Keep raw traces, personal data, and environment secrets out of issue attachments.

See the [development checks](README.md#development) before submitting. Changes that affect reported metrics should include an updated manifest and explain the experiment and split settings.
